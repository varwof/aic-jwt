WIT-SVID Issuance-Control Demo

AIC DA/PA gate WIT-SVID issuance → WPT PoP → verifier report · all crypto generated locally with WebCrypto

Semantics

  • WIT is an identity + PoP (cnf) credential. AIC's principal/capability binding happens at the issuance decision; it never enters the WIT claims.
  • Standard FetchWITSVID semantics: the server generates the wit_svid_key and delivers it with the response. This demo simulates that.
  • WIT MUST NOT be used as a bearer token; it must be accompanied by a WPT (PoP).
  • Relationship to draft-01: this page demonstrates an issuance-control integration on the SPIFFE WIT-SVID supply side, separate from (and additive to) the AIC-JWT demo.
